> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stage 3 (`andrej-karpathy-rdb-mybatis`) 가 `--lane vanilla|nexacro` 플래그로 두 개의 산출물 lane 을 지원한다. 기본은 `nexacro` (하위호환 100%). `vanilla` lane 은 NexacroBase / NexacroResult / DataSet 의존성 없이 순수 Spring + MyBatis POJO/REST 컨트롤러를 emit한다.

**Architecture:**
- **Lane = template family + context override + endpoint contract.** 코드는 단일 파이프라인, lane 별로 분기되는 지점은 (1) template 선택, (2) precompute 의 `lib_prefix`/`save_branches`, (3) endpoints_emitter 의 contract 모양, (4) compile.py 의 default `--package`.
- **Vanilla 산출물 모양**: POJO entity (no extends), `@RestController` + `@PostMapping("/api/{name}")` + `@GetMapping("/api/{name}")`, DTO List<Map<String,Object>> 기반 단순 CRUD (save 는 `rowType` 필드를 Map 안 자체 키로 디스패치 — Nexacro DataSet 미사용).
- **Lane 간 공유**: mapper interface, mapper.xml, service interface, DDL 변환은 그대로 (이미 vanilla — Nexacro 의존성 없음).
- **Stage 4 영향**: nexacro lane endpoints.json 모양 불변 → Stage 4 (rdb-nexacro) 무변경. vanilla lane endpoints.json 은 v2 엔드포인트 컨트랙트 (REST 모양) — Stage 4 가 소비하지 않음 (별도 web-frontend 플러그인이 v0.4+ 에 도입될 자리).
- **하위호환**: 모든 기존 테스트/golden fixture (lane 없거나 default) → nexacro 동작과 동일. v0.1.4 endpoints.json 의 `version: 1` 유지 (vanilla 만 `version: 2`).

**Tech Stack:** Python 3.11+, PyYAML, Jinja2, pytest. JDK17 + Spring Boot 3 (vanilla), Nexacro uiadapter jakarta (nexacro lane 유지).

```python
import json
import pathlib


def build_endpoints_payload(entities, context_path="/uiadapter", lane="nexacro"):
    if lane == "vanilla":
        return _vanilla_payload(entities, context_path)
    return _nexacro_payload(entities, context_path)


def _nexacro_payload(entities, context_path):
    out_entities = []
    for e in entities:
        name = e["name"]
        base = f"/{name}"
        out_entities.append({
            "name": name,
            "endpoint_base": base,
            "endpoints": [
                {
                    "method": "select_datalist_map",
                    "http_path": f"{base}/select_datalist_map.do",
                    "input": {"dsSearch": "param-dataset"},
                    "output": {"output1": "list-dataset"},
                },
                {
                    "method": "save_datalist_map",
                    "http_path": f"{base}/save_datalist_map.do",
                    "input": {"dataList": "row-dispatch"},
                    "output": {},
                },
            ],
        })
    return {"version": 1, "context_path": context_path, "entities": out_entities}


def _vanilla_payload(entities, context_path):
    out_entities = []
    for e in entities:
        name = e["name"]
        base = f"/api/{name}"
        out_entities.append({
            "name": name,
            "endpoint_base": base,
            "endpoints": [
                {"method": "select", "http": "GET",  "http_path": base,
                 "input": {"params": "query-map"}, "output": {"body": "list-of-map"}},
                {"method": "save",   "http": "POST", "http_path": base,
                 "input": {"body": "list-of-map"}, "output": {"body": "int-affected"}},
            ],
        })
    return {"version": 2, "lane": "vanilla", "context_path": context_path, "entities": out_entities}


def write_endpoints_json(out_root, payload):
    out = pathlib.Path(out_root) / "endpoints.json"
    out.parent.mkdir(parents=True, exist_ok=True)
    out.write_text(
        json.dumps(payload, indent=2, ensure_ascii=False) + "\n",
        encoding="utf-8",
    )
    return out
```

- Controller: `org.springframework.web.bind.annotation.{RestController, RequestMapping, GetMapping, PostMapping, RequestBody, RequestParam}`

- `GET  /api/<entity>` → `select_<entity>_datalist_map(Map params)` → `List<Map<String,Object>>`
- `POST /api/<entity>` → `save_<entity>_datalist_map(List<Map<String,Object>> rows)` → `int affected`

요청 body 의 각 row Map 안에 `_rowType` 필드 (`"I" | "U" | "D"`) 로 라우팅.

```java
String rowType = String.valueOf(row.getOrDefault("_rowType", ""));

else if ("D".equals(rowType)) { mapper.delete_<entity>_map(row); }
```
