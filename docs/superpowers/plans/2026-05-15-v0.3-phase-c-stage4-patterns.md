> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stage 4 (`andrej-karpathy-rdb-nexacro`) 의 form layout 을 하드코딩된 단일 2-tier 형식에서 **명명된 file-based pattern 카탈로그** (`D2` / `F1` / `C1`) 로 분리하고, blueprint entity frontmatter `pattern:` 필드로 선택. 사용자가 만든 pattern 은 `/contribute` 워크플로로 글로벌 카탈로그 (`~/.karpathy-rdb/catalog/patterns/`) 에 복리식 누적 가능.

**Architecture:**
- **3 named patterns** (file-based Jinja2 templates):
  - `D2` (Detail 2-tier, current default): Search 패널 + Grid + Action 버튼. 다행/CRUD 위주.
  - `F1` (Form 1-tier): 단일 record 편집 폼. 마스터-디테일의 디테일 측, 1:1 entity.
  - `C1` (Card 1-tier): 카드 목록 + Action. 읽기/단순 선택 위주.
- **Pattern 선택 우선순위**: (1) entity profile.md frontmatter `pattern: <name>`, (2) CLI `--default-pattern <name>`, (3) `D2` 기본.
- **Pattern 카탈로그 위치**: (1) Stage 4 번들 `<repo>/.claude/skills/karpathy-rdb-nexacro/patterns/<name>/`, (2) 글로벌 fallback `~/.karpathy-rdb/catalog/patterns/<name>/`. 둘 다 없으면 명시적 에러.
- **각 pattern 디렉터리 구조**:
  ```
  patterns/<name>/
    manifest.yaml        # name, kind, description, required_cardinality (선택)
    form.xfdl.j2         # 메인 form 템플릿
    README.md            # 사람 읽기용 문서
  ```
- **Blueprint v1 호환**: `pattern:` 은 선택 필드. 미지정 entity 는 D2 로 처리. `version: 1` 유지.
- **/contribute 확장**: Stage 1 `04-contribute.md` 에 pattern 디렉터리도 글로벌 카탈로그로 승격하는 옵션 추가. Karpathy 정신 (명시적 확인, 자동 머지 금지) 유지.

**Tech Stack:** Python 3.11+, Jinja2, PyYAML, pytest. Stage 4 의 `form_composer.py` / `form_gen.py` 만 수정. Stage 1/2/3 은 blueprint spec doc 만 (선택 필드 1줄).

```python
# scripts/pattern_loader.py
import pathlib
import yaml
from dataclasses import dataclass


class PatternNotFoundError(Exception):
    pass


@dataclass
class ResolvedPattern:
    name: str
    template_path: pathlib.Path
    manifest: dict
    source: str  # "bundled" or "global"


def resolve_pattern(name, bundled_root, global_root=None):
    for label, root in (("bundled", bundled_root), ("global", global_root)):
        if root is None:
            continue
        pat_dir = pathlib.Path(root) / name
        manifest = pat_dir / "manifest.yaml"
        tpl = pat_dir / "form.xfdl.j2"
        if manifest.exists() and tpl.exists():
            return ResolvedPattern(
                name=name,
                template_path=tpl,
                manifest=yaml.safe_load(manifest.read_text(encoding="utf-8")) or {},
                source=label,
            )
    raise PatternNotFoundError(
        f"Pattern '{name}' not found in bundled or global catalog."
    )
```
