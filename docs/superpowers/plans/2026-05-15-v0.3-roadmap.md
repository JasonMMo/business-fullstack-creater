## Milestone Gate 절차 (각 Phase 완료 직후)

1. **5축 키워드 자체 점수 산정** (1~5점):
   - 키워드 1: 반복 데이터 효율 관리 — 같은 정보를 두 번 정의하지 않는가?
   - 키워드 2: 도메인·엔티티 지식 누적 — 한 번 만든 것이 다음 프로젝트에서 살아 있는가?
   - 키워드 3: 풍부한 Seeds — 새 프로젝트 시작 시 출발점이 진짜로 더 풍부해졌는가?
   - 키워드 4: 완성도 높은 WAR — 최종 산출물 품질 향상에 직접 기여하는가?
   - 키워드 5: Karpathy 정신 — LLM이 지식 컴파일러, 파일 기반, 복리식 축적 유지?
2. **의도와 어긋난 부분 명시** (없으면 "없음")
3. **사용자에게 짧은 한 줄 보고** (예: "M-A 완료 — 점수 4·3·3·5·5, 다음 진행")
4. **어긋남 / 평균 < 3 / 회귀 발생 시 → 즉시 멈추고 사용자 보고**
