**Goal:** 주어진 form 목록 (name, label, url-prefix) 을 frameLogin.xfdl 의 `<Dataset id="dsSample">` 에 `<Row>` 로 append. **xml.etree 사용 금지** — xfdl 은 BindItem 등 비표준 self-closing 처리가 있어 etree 가 재포맷하면 nexacro Studio 에서 차이 발생. **regex + 문자열 삽입** 으로 dsSample 의 `</Rows>` 직전에 신규 `<Row>` 삽입.

dsSample 필수 컬럼 (본 도구가 emit 하는 ColumnInfo):
```
level, groupId, menuId, menuNm, menuUrl, sortNo, upMenuId, useYn, auth
```

**Schema mismatch 처리:** dsSample 의 `<ColumnInfo>` 를 파싱하여 실 컬럼 목록을 추출. 위 필수 9개 중 빠진 게 있으면 `SchemaMismatch` 예외에 두 정보를 함께 담아 raise:
1. target 실 컬럼 목록 (e.g. `["level","groupId","menuId","menuNm","menuUrl","sortNo","upMenuId","useYn"]` — `auth` 없음)
2. 본 도구가 필요로 하는 컬럼 목록 (위 9개)

호출자 (stage5_overlay) 는 예외를 잡아 stderr + scaffold-report.md 에 두 목록을 사용자 메시지로 출력하고, menu 단계만 skip (다른 단계 계속).

도메인이 `Order` 이고 entity 가 `order, order_item, payment` 라면 다음 row 들이 추가됨:
- Row 1: level=0, groupId=`BIZ_ORDER`, menuId=`BIZ_ORDER`, menuNm=`주문관리`, sortNo=`10`, upMenuId=`(root)`, useYn=`Y` — 도메인 그룹 (1회)

```python
# scripts/menu_injector.py
import re, pathlib
from typing import Sequence, Tuple

REQUIRED_COLUMNS = ["level", "groupId", "menuId", "menuNm", "menuUrl",
                    "sortNo", "upMenuId", "useYn", "auth"]

class SchemaMismatch(Exception):
    def __init__(self, target_cols: list[str], required: list[str], path: pathlib.Path):
        self.target_cols = target_cols
        self.required = required
        self.path = path
        missing = [c for c in required if c not in target_cols]
        super().__init__(
            f"dsSample column schema mismatch in {path}.\n"
            f"  target ColumnInfo: {target_cols}\n"
            f"  required by tool : {required}\n"
            f"  missing          : {missing}\n"
            f"  → Add the missing columns to dsSample <ColumnInfo>, or map them via blueprint."
        )

# locate dsSample block, capture ColumnInfo + Rows boundary
_DATASET_RE = re.compile(
    r'<Dataset\s+id="dsSample">(?P<body>.*?)</Dataset>',
    re.DOTALL,
)
_COLINFO_RE = re.compile(r'<Column\s+id="([^"]+)"', re.DOTALL)
_ROWS_CLOSE_RE = re.compile(r'(\s*)(</Rows>)')

_ROW_TEMPLATE = (
    "          <Row>\n"
    '            <Col id="level">{level}</Col>\n'
    '            <Col id="groupId">{groupId}</Col>\n'
    '            <Col id="menuId">{menuId}</Col>\n'
    '            <Col id="menuNm">{menuNm}</Col>\n'
    '            <Col id="menuUrl">{menuUrl}</Col>\n'
    '            <Col id="sortNo">{sortNo}</Col>\n'
    '            <Col id="upMenuId">{upMenuId}</Col>\n'
    '            <Col id="useYn">Y</Col>\n'
    '            <Col id="auth">YYYYYY</Col>\n'
    "          </Row>\n"
)

def inject_menu_rows(
    xfdl_path: pathlib.Path,
    *,
    domain_id: str,
    domain_label: str,
    domain_sort: int,
    entries: Sequence[Tuple[str, str, str]],   # (slug, label, url)
) -> None:
    text = xfdl_path.read_text(encoding="utf-8")
    m = _DATASET_RE.search(text)
    if not m:
        raise RuntimeError(f"<Dataset id=\"dsSample\"> not found in {xfdl_path}")
    body = m.group("body")
    target_cols = _COLINFO_RE.findall(body)
    if not all(c in target_cols for c in REQUIRED_COLUMNS):
        raise SchemaMismatch(target_cols, REQUIRED_COLUMNS, xfdl_path)

    def _has_menu(mid: str) -> bool:
        return f'<Col id="menuId">{mid}</Col>' in body

    new_rows = []
    if not _has_menu(domain_id):
        new_rows.append(_ROW_TEMPLATE.format(
            level=0, groupId=domain_id, menuId=domain_id,
            menuNm=domain_label, menuUrl="", sortNo=domain_sort,
            upMenuId="(root)",
        ))
    for i, (slug, label, url) in enumerate(entries, start=1):
        mid = f"{domain_id}_{slug.upper()}"
        if _has_menu(mid):
            continue
        new_rows.append(_ROW_TEMPLATE.format(
            level=1, groupId=domain_id, menuId=mid,
            menuNm=label, menuUrl=url, sortNo=i * 10,
            upMenuId=domain_id,
        ))
    if not new_rows:
        return

    # insert before </Rows> within the dsSample body only
    new_body, n = _ROWS_CLOSE_RE.subn(
        lambda mm: "".join(new_rows) + mm.group(1) + mm.group(2),
        body,
        count=1,
    )
    if n != 1:
        raise RuntimeError(f"</Rows> not found in dsSample of {xfdl_path}")
    new_text = text[:m.start("body")] + new_body + text[m.end("body"):]
    xfdl_path.write_text(new_text, encoding="utf-8")
```

```python
# scripts/typedef_merger.py
import re, pathlib
_SERVICES_CLOSE = re.compile(r'(\s*)(</Services>)')

def merge_service(path: pathlib.Path, *, prefixid: str, url: str,
                  cachelevel: str = "session") -> None:
    text = path.read_text(encoding="utf-8")
    if f'prefixid="{prefixid}"' in text:
        return  # idempotent
    entry = (
        f'    <Service prefixid="{prefixid}" type="form" '
        f'url="{url}" cachelevel="{cachelevel}" version=""/>\n'
    )
    new_text, n = _SERVICES_CLOSE.subn(
        lambda m: entry + m.group(1) + m.group(2), text, count=1
    )
    if n != 1:
        raise RuntimeError(f"</Services> not found in {path}")
    path.write_text(new_text, encoding="utf-8")
```

**Public API:**
```python
def run_overlay(
    *,
    out_dir: pathlib.Path,         # scaffold orchestrator 의 out_dir (3-mybatis, 4-nexacro 포함)
```

**절차:**
1. **Java overlay + package rename:** `<out>/3-mybatis/src/main/java/com/example/<slug>/**/*.java` 를 읽어 다음 두 치환 수행 후 `<target>/src/main/java/com/nexacro/uiadapter/<slug>/**/*.java` 에 write:
   - `package com.example.<slug>` → `package com.nexacro.uiadapter.<slug>`
   - `import com.example.<slug>.` → `import com.nexacro.uiadapter.<slug>.`
   디렉터리 구조는 `com/example/<slug>/sub/...` → `com/nexacro/uiadapter/<slug>/sub/...` 로 재배치. 충돌 시 `.bak` 후 덮어쓰기 (`--overlay-force` 필요).
2. **Mapper xml + schema/data.sql overlay:** `<out>/3-mybatis/src/main/resources/...` → `<target>/src/main/resources/...`. MyBatis mapper xml 내 `namespace="com.example.<slug>...`/`type="com.example.<slug>...`/`resultType="com.example.<slug>...` 도 동일 치환. `schema.sql`/`data.sql` 는 `.scaffold.bak` 백업.
3. **xfdl form 복사:** `<out>/4-nexacro/nxui/_form_/*.xfdl` → `<target>/nxui/packageN/<domain_slug>/*.xfdl` (신규 prefix 디렉터리).
4. **menu injection:** `menu_injector.inject_menu_rows(<target>/nxui/packageN/frame/frameLogin.xfdl, ...)`. `SchemaMismatch` 예외 발생 시 catch 하여 report 에 두 컬럼 목록 + 사용자 메시지 기록, 다른 단계는 계속.
5. **typedef merge:** `typedef_merger.merge_service(<target>/nxui/packageN/typedefinition.xml, prefixid=domain_slug, url=f"./{domain_slug}/")`.
6. **report:** report dict 를 return 하여 caller (orchestrator) 가 scaffold-report.md 에 기록 (copied/renamed/backed_up 카운트 + menu schema_mismatch warning 텍스트).

> **Package rename 정책:** 사용자 지시에 따라 `com.example.<slug>` → `com.nexacro.uiadapter.<slug>` 로 overlay 시 자동 치환. Stage 3 산출의 `--package com.example.<slug>` 가정 (orchestrator 가 보장). slug 는 `domain_slug` 값 (e.g. `order`). 단, **base scaffold 에 동일 클래스명이 이미 존재할 가능성 거의 0** — package 가 `com.nexacro.uiadapter` 루트이고 base scaffold 의 `controller/service/mapper/domain/service/impl/config` 는 빈 .gitkeep 상태이므로.
