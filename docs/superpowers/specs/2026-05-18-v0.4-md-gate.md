## 의도와 어긋난 부분 명시

- **per-task CLI 검증 갭 (T1~T7)** — Phase C lesson "스펙 문서 변경 = 반드시 코드 변경 동반 확인"을 phase plan에 체크리스트로 추가했으나, Task 별 CLI `--help` 확인이 T8 golden E2E 실행 전까지 유예됐음. 결과적으로 T8에서 버그 3건이 일괄 발견되어 fix 커밋이 집중됨. E2E 규율은 정상 작동했지만 **task-level 조기 검증이 빠졌다는 process gap**은 남음 — 다음 phase에서 각 wiring task 완료 즉시 `--help` + smoke 단언을 test에 포함하는 패턴 적용 권장.
- **USER SMOKE TEST CHECKPOINT 우회** — T7 plan은 사용자 확인 후 T8 진입을 명시했으나, 사용자가 연속 실행 pre-authorize했고 T8 golden이 실질적으로 smoke를 대체함. 기능적으로는 동등하지만 plan 문서와 실행 순서가 불일치.
- **vanilla lane 미검증** — `--lane vanilla` 경로는 오케스트레이터에 wired되어 있으나 golden E2E는 `nexacro` lane만 검증. Stage 3 vanilla 산출 + 이후 단계 연결은 실 사용 시 1회 확인 권장 (vanilla는 Stage 4 form_gen 비대상이므로 4-nexacro stage는 vanilla 모드에서 자동 skip됨 — 이는 의도된 설계).
- **`_schema.md` frontmatter 미검증** (T8 전) — Stage 1 wiki 생성 계약에 frontmatter 요구사항이 plan에 명시되지 않았음. golden에서 발견되어 fix됨.

기타 어긋남: **없음**.
