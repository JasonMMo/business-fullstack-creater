## 의도와 어긋난 부분 명시

- **`service_pascal` 누적 미흡** — 현재는 `--service-name` 또는 `domain_slug` 도출. 같은 도메인을 다른 프로젝트에서 재 init 할 때 service 이름이 자동으로 동일하다는 보장은 `domain_slug` 일치에 의존 (Korean 도메인은 derive_slug 가 "domain" fallback). 향후 wiki `_schema.md` frontmatter 에 `service_pascal:` 을 명시·누적시키면 진짜 카탈로그 자산화. v0.4.1 후보.
- **HSQLDB 실 DB 부팅 미관측** — golden E2E 는 생성물의 파일 존재만 검증 (data.sql 비어있지 않음 + xfdl 매핑). 실제 Spring Boot 띄워 schema.sql + data.sql 자동 로드를 확인하는 통합 테스트는 본 Phase 범위 외. v0.4.x 사용자 검증 단계 1회 권장.
- **Stage 2 → Stage 3 seed 디렉토리 형상 가정** — `<out>/2-ddl/seed/*.sql` 형상에 의존. Stage 2 가 향후 dir 구조를 바꾸면 silent skip (orchestrator는 디렉토리 비어있으면 `--seed-dir` 미전달). 다행히 에러는 아니지만 회귀 감지 안 됨 → E6 가 data.sql 비어있지 않음을 단언하므로 1차 안전망 있음.

기타 어긋남: **없음**.
